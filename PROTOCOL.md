## 1. Measurement Boundaries

### Included
- Initialization (corpus generation, tokenizer setup)
- Indexing (inverted index / CSR build / FTS5 index)
- Query execution (scoring, ranking, top-k selection)
- Evidence retrieval (RPR Scout/Expand/Evidence/Pulse events)
- Task completion verification (result correctness, recall@k)
- Background scouting (RPR wave expansion)
- Update/delete/reopen lifecycle (conceptual; not timed in this run)

### Excluded
- Model inference (held constant across arms)
- Network I/O (local-only, localhost)
- Human interaction time

## 2. Corpus Generation (Deterministic, Seed 8001)

All comparators use identical corpus generated by LCG:

```
rng_state = (rng_state * 1664525 + 1013904223) & 0xFFFFFFFF
topic_idx = rng_state % 5
doc_text = f"test document {i} with {topic} terms nile river pharaoh ziggurat cyrus legion"
```

- **Topics:** egypt, greece, mesopotamia, persia, rome
- **Doc IDs:** 1..N (sequential)
- **Timestamps:** 1.0 + i * 0.001
- **Scope/Principal:** 1 / 1 (uniform)

## 4. Metrics

| Metric | Definition |
|--------|------------|
| Ingest time (ms) | Corpus generation + insertion into index |
| Index build time (ms) | Inverted index / CSR array construction |
| Query median (ms) | Median latency over 10 iterations per query |
| Query p95 (ms) | 95th percentile latency over 10 iterations |
| QPS | Queries per second (concurrent/sequential simulated) |
| Memory (MB) | Estimated resident memory (terms + postings + docs + flat arrays) |
| Result count | Number of documents returned per query |

### Comparator-Specific Notes

**BM25S:** Tokenization with `bm25s.tokenize()`, index with `bm25s.BM25().index()`, queries with `retrieve(Tokenized, k=)`. Query results include `.documents` / `.scores` numpy arrays.

**rank_bm25:** Tokenization with `re.findall(r'[a-zA-Z0-9]+', t.lower())`, index with `BM25Okapi()`, queries with `get_top_n(tokens, texts, n=k)`.

**SQLite FTS5:** WAL mode, synchronous=OFF, cache_size=256MB. Multi-term queries use quoted phrase matching (`"nile pharaoh"`), which returns 0 results when terms don't appear adjacently — a known FTS5 phrase-matching limitation.

**MITRE Goose:** Fast-path CSR scoring, pre-computed IDF, ring buffer RPR queue. Query via `score_query_fast(tokenized_terms)`.
